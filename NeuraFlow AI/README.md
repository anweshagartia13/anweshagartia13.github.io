## 🛠 Tech Stack

- **Framework**: React 18 + Vite 5
- **Styling**: Tailwind CSS v3 + Custom Glassmorphism CSS & Radial Ambient Lights
- **Animations**: Framer Motion + HTML5 Canvas Particle Engine + Canvas Confetti
- **Icons**: Lucide React
- **Deployment**: Vercel Global Edge Network (99.99% Uptime SLA)

## 📄 Pages & Architecture Overview

1. **Home Page (`/home`)**: Hero section with live typing effect (*"Transforming Businesses with Artificial Intelligence"*), interactive neural node animation, partner logos ribbon, live counters ($140M+ client cost saved), features grid, service preview, and case study video demo modal.
2. **About Page (`/about`)**: Company story, mission, vision, 4 core values, interactive company timeline (2020–2026), executive leadership cards with bios/socials, and industry awards.
3. **Services Page (`/services`)**: 8 interactive service cards (AI Chatbots, ML Models, Computer Vision, NLP, Predictive Analytics, Automation, Consulting, Cloud AI) with technical blueprint modals.
4. **Portfolio Page (`/portfolio`)**: Filterable commercial case studies across Healthcare, FinTech, Retail, AgriTech, and Enterprise with quantified ROI impact metrics.
5. **Pricing Page (`/pricing`)**: Monthly vs Annual billing toggle (20% discount), Starter ($2,999/mo), Professional ($7,499/mo), Enterprise tiers, detailed feature matrix, and interactive **ROI Calculator**.
6. **Testimonials Page (`/testimonials`)**: Sector-filterable 5-star customer reviews, customer photos, and security compliance badges (SOC2 Type II, ISO 27001, GDPR).
7. **Blog Page (`/blog`)**: 6 AI research articles with category filters, search bar, author metadata, and full article reader modal.
8. **FAQ Page (`/faq`)**: 12 categorized accordion questions covering Security, SLAs, On-Premise deployment, Pricing, and IP ownership.
9. **Contact Page (`/contact`)**: Consultation request form with validation/confetti, global office hub selector (SF, London, Tokyo, Singapore), and interactive map representation.
10. **Careers Page (`/careers`)**: Open job positions (AI Researcher, MLOps Engineer, Full-Stack Engineer, Product Designer) with application modal.
11. **Privacy Policy (`/privacy`)**: Legal terms detailing Zero-Data Training guarantees, SOC2 encryption, data retention, and GDPR rights.
12. **Terms & Conditions (`/terms`)**: Commercial agreement covering 100% IP model weight ownership, SLAs, and acceptable use.
13. **404 Page (`/404`)**: Futuristic diagnostic terminal readout with quick redirect controls.

# 2. Install dependencies
npm install

npm run dev

# 4. Build for production
npm run build
